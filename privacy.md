# StudentOS Privacy Policy

**Last updated: October 16, 2026**

## 1. Overview

StudentOS is a personal, non-commercial university assistant built using Python and Telegram. It helps manage class schedules, assignments, deadlines, and reminders.

## 2. Information Processed

StudentOS processes the following information to provide its features:

- University class schedules and classroom information.
- Assignments and deadlines entered by the user.
- Telegram user ID and messages sent to the bot.
- Application settings and backup files.

## 3. Google Drive Access

When Google Drive backups are enabled, StudentOS uses the Google Drive API through rclone to store and manage its backup files.

The integration is intended to access only files needed for StudentOS backups, not unrelated personal documents.

Backup files are intended to be encrypted before uploading to Google Drive.

## 4. Data Storage and Security

StudentOS stores application data on a private cloud server.

Access credentials and authentication tokens are kept separately from the public source code.

Local backups are automatically rotated. Cloud backups may be retained until deleted by the operator.

## 5. Data Sharing

StudentOS does not sell personal data or use it for advertising.

Data is processed through the services required to operate the application, including Telegram, Oracle Cloud, and Google Drive when connected.

## 6. Data Control

The application operator can delete stored assignments, backup files, and application data.

Google Drive access can be revoked through Google Account security settings.
